##### TYRE #####
SUMMARY:
Use tyre_data/TNO_car205_60R15.tir (FITTYP=62, MF-Tyre/MF-Swift 6.2, measured by TNO/Delft on dry asphalt). This is not a preference — it is the *provenance* of qss.py: its D-term is muy = PDY1 + PDY2*(Fz-4000)/4000 = 0.8784 - 16.11e-6*(Fz-4000), which evaluated at Fz=2477 gives 0.90294 with slope -16.11e-6/N. qss.py's TYRE = dict(mu_ref=0.903, Fz_ref=2477.0, s=-16.1e-6) IS this line, rounded. Any other .tir breaks the reference truth. (car145_70R13.tir and car205_60R19.tir carry byte-identical MF coefficients with only UNLOADED_RADIUS/WIDTH changed — they are the same TNO fit re-badged, confirming that geometry is the only thing you are meant to swap.)

RESCALING VERDICT — do NOT rescale FNOMIN. Set LFZO = 1.0, LMUX = 1.0, LMUY = 1.0, LKY = 1.0, LKX = 1.0. The brief's premise ("FNOMIN for a 1010 kg car is ~2500 N") conflates the CAR's operating wheel load with the TYRE's rated load. FNOMIN is a property of the tyre: a 175/65R14 82T has load index 82 = 475 kg = 4660 N, so a reference load of 4000 N (86% of max) is the correct FNOMIN for the Corsa tyre too — the same number the file already carries. And the arithmetic is decisive: load sensitivity in MF is s = PDY2/(LFZO*FNOMIN). At LFZO=1 that is -0.06445/4000 = -16.11e-6/N, matching qss exactly. At the proposed LFZO = 2500/4000 = 0.625 it becomes -0.06445/2500 = -25.78e-6/N — a 60% steeper load-sensitivity slope that would destroy the whole flank-wing argument (crossover.py's marginal_mu, the sqrt(mu_r/mu_f) cap, everything). Rescale ONLY the geometry: UNLOADED_RADIUS 0.3135 -> 0.2915 m, WIDTH 0.205 -> 0.175, ASPECT_RATIO 0.60 -> 0.65, RIM_RADIUS 0.1905 -> 0.1778. R0 enters only Mz (Dt, Dr, s-arm), scaling pneumatic trail by 0.930.

SYMMETRISATION IS MANDATORY. Zero the 13 conicity/ply-steer coefficients that are even in camber: PHY1 PHY2 PVY1 PVY2 PHX1 PHX2 PVX1 PVX2 QHZ1 QHZ2 QDZ6 QDZ7 QSX1. Keep every camber-odd shift (PVY3 PVY4 QHZ3 QHZ4 QDZ8 QDZ9 QDZ10 QDZ11) and keep RHX1 RHY1 RHY2 (the combined-slip weighting functions self-normalise at their own shift, so G(0) = 1 regardless). Measured effect: with the raw file, peak|Fy|/Fz at 2477 N is 0.9233 for positive alpha and 0.8830 for negative — 2.3% above the qss law and directionally asymmetric, so the sim car pulls to one side at zero steer and Mz(0,0) = +1.75 Nm per wheel gives a phantom self-centring offset. After symmetrisation, peak|Fy|(Fz) == muy(Fz)*Fz to 5 significant figures at every load, Fx(0)=Fy(0)=Mz(0)=0 exactly, and the model is exactly odd in (kappa, alpha).

VERIFIED AGAINST qss.py. Monkey-patching qss.fy_max with the symmetrised MF peak lateral force reproduces the reference truth to 0.005%: R=50 -> 20.5669 m/s (qss 20.5679), R=100 -> 29.0860 (qss 29.0875), R=130 -> 31.8802 POWER-limited (identical), max_ay at 29.09 m/s = 0.86238 g (qss 0.86247), qss.balance(100) unchanged: front-limited, util_f 1.000 / util_r 0.9523, margin 4.77%, roll 4.60 deg. Front-axle capacity 5210 N (MF) vs 5212.7 N (qss).

Wet is LMUX = LMUY = mu_scale = 0.55/0.87 = 0.63218, applied per-call. Because By = Kya/(Cy*Dy), scaling LMUY leaves cornering stiffness untouched (Kya stays -39150 N/rad) and moves the peak inward from 8.54 deg to 5.40 deg — physically correct wet behaviour, and it comes free.

Low speed and zero speed are handled by a backward-Euler relaxation-length ODE on tan(kappa) and tan(alpha) — unconditionally stable, degenerates to a pure integrator (a tyre spring) at Vx = 0, verified stable at dt up to 10 ms — plus a raised-cosine low-speed viscous damper below VXLOW = 1 m/s and a friction-ellipse cap at e = 1.05 so the damper can never manufacture grip. Verified: a 2000 N standstill push produces |Vy| < 1e-4 m/s; a 12000 N push slides at 3.04 m/s2 against the ideal 3.05; braking to a dead stop from 5 m/s at 1.07 g leaves 0.02 m/s residual creep; a forced reversal through Vx = 0 produces no NaN and max |Fx| of 177 N.

Speed: 1.78 us per full combined Fx+Fy+Mz evaluation in CPython 3.11 on this machine, measured over 200k calls. Four tyres at 1000 Hz = 0.71% of one core. There is no performance problem; the only rules are parse the .tir exactly once into a module singleton, and use the cheap stiffnesses() helper for the relaxation lengths instead of a second full evaluation.

EQUATIONS:
  CONVENTION. Wheel-carrier frame, x forward, y left, z up. alpha = atan2(Vcy, |Vcx|)  (SAE slip angle: positive when the contact point slides toward +y). kappa = -Vsx/|Vx|, Vsx = Vx - omega*Re. Positive alpha gives NEGATIVE Fy (restoring). Positive gamma gives negative Fy too (camber thrust in the same sense). Absolute-value denominators everywhere make the model sign-symmetric in Vx, so reversing works; the only thing that must flip in reverse is Mz.
  PRE. Fz = min(max(Fz_in, 0.0), FZMAX=10000).  If Fz < FZ_EPS = 50: return (0,0,0) and decay the contact states by *=0.9 per step.
  E1.  Fz0 = LFZO*FNOMIN = 1.0*4000 = 4000 N ;  inv_Fz0 = 1/4000 ;  dfz = (Fz - Fz0)*inv_Fz0
  E2.  LMX_ = LMUX*mu_scale ;  LMY_ = LMUY*mu_scale        # single fused friction scaler, used everywhere below
  E3.  Cx  = PCX1*LCX
  E4.  mux = (PDX1 + PDX2*dfz)*(1 - PDX3*gamma^2)*LMX_ ;  Dx = mux*Fz
  E5.  Ex  = (PEX1 + PEX2*dfz + PEX3*dfz^2)*(1 - PEX4*sgn(kappa))*LEX ;  if Ex > 1: Ex = 1
  E6.  Kxk = Fz*(PKX1 + PKX2*dfz)*exp(PKX3*dfz)*LKX
  E7.  Bx  = Kxk/(Cx*Dx) ;  bx = Bx*kappa
  E8.  Fx0 = Dx*sin(Cx*atan(bx - Ex*(bx - atan(bx))))        # PHX1=PHX2=PVX1=PVX2=0 after symmetrisation
  E9.  Cy  = PCY1*LCY
  E10. muy = (PDY1 + PDY2*dfz)*(1 - PDY3*gamma^2)*LMY_ ;  Dy = muy*Fz
  E11. Kya = PKY1*Fz0*(1 - PKY3*|gamma|)*sin(PKY4*atan(Fz/((PKY2 + PKY5*gamma^2)*Fz0)))*LKY      # MF6.2 form. NOTE: PKY1 = -15.314 so Kya < 0. Do NOT copy mf_eval.py's non-mf6 branch: it uses a different sin(2*atan(...)) shape AND multiplies by LFZO a second time.
  E12. Kyg0 = Fz*(PKY6 + PKY7*dfz)*LKYC                      # MF6.2 camber stiffness. mf_eval.py's PHY3*gamma is the MF5.2 form and is WRONG here (PHY3 does not exist in a FITTYP=62 file).
  E13. SVyg = Fz*(PVY3 + PVY4*dfz)*gamma*LKYC*LMY_
  E14. SVy  = SVyg                                            # PVY1=PVY2=0 after symmetrisation
  E15. SHy  = (Kyg0*gamma - SVyg)/Kya                         # PHY1=PHY2=0 after symmetrisation
  E16. By = Kya/(Cy*Dy) ;  ay = alpha + SHy
  E17. Ey = (PEY1 + PEY2*dfz)*(1 + PEY5*gamma^2 - (PEY3 + PEY4*gamma)*sgn(ay))*LEY ;  if Ey > 1: Ey = 1
  E18. by = By*ay ;  Fy0 = Dy*sin(Cy*atan(by - Ey*(by - atan(by)))) + SVy
  E19. DEFINE the combined-slip weighting kernel:  Mc(B,C,E,x) = cos(C*atan(B*x - E*(B*x - atan(B*x))))
  E20. Bxa = (RBX1 + RBX3*gamma^2)*cos(atan(RBX2*kappa))*LXAL ;  Cxa = RCX1 ;  Exa = min(REX1 + REX2*dfz, 1)
  E21. Gxa = Mc(Bxa,Cxa,Exa, alpha + RHX1) / Mc(Bxa,Cxa,Exa, RHX1)
  E22. Fx = Gxa*Fx0
  E23. Byk = (RBY1 + RBY4*gamma^2)*cos(atan(RBY2*(alpha - RBY3)))*LYKA ;  Cyk = RCY1 ;  Eyk = min(REY1 + REY2*dfz, 1)
  E24. SHyk = RHY1 + RHY2*dfz ;  Gyk = Mc(Byk,Cyk,Eyk, kappa + SHyk) / Mc(Byk,Cyk,Eyk, SHyk)
  E25. DVyk = muy*Fz*(RVY1 + RVY2*dfz + RVY3*gamma)*cos(atan(RVY4*alpha))
  E26. SVyk = DVyk*sin(RVY5*atan(RVY6*kappa))*LVYKA           # kappa-induced side force; +138 N at Fz=3022, kappa=0.10, alpha=0
  E27. Fy = Gyk*Fy0 + SVyk
  E28. SHt = (QHZ3 + QHZ4*dfz)*gamma ;  at = alpha + SHt      # QHZ1=QHZ2=0 after symmetrisation
  E29. Bt = (QBZ1 + QBZ2*dfz + QBZ3*dfz^2)*(1 + QBZ4*gamma + QBZ5*|gamma|)*LKY/LMY_    # NOTE the DIVISION by the friction scaler
  E30. Ct = QCZ1 ;  Dt = Fz*(R0/Fz0)*(QDZ1 + QDZ2*dfz)*(1 + QDZ3*gamma + QDZ4*gamma^2)*LTR
  E31. Et = (QEZ1 + QEZ2*dfz + QEZ3*dfz^2)*(1 + (QEZ4 + QEZ5*gamma)*0.6366197723675814*atan(Bt*Ct*at)) ;  if Et > 1: Et = 1
  E32. SHf = SHy + SVy/Kya ;  ar = alpha + SHf
  E33. Br = QBZ9*LKY/LMY_ + QBZ10*By*Cy
  E34. Dr = Fz*R0*((QDZ8 + QDZ9*dfz)*gamma + (QDZ10 + QDZ11*dfz)*gamma*|gamma|)*cos(alpha)*LMY_    # QDZ6=QDZ7=0 after symmetrisation, so Mzr vanishes identically at gamma=0
  E35. rat = Kxk/Kya ;  ateq = sgn(at)*sqrt(at^2 + rat^2*kappa^2) ;  areq = sgn(ar)*sqrt(ar^2 + rat^2*kappa^2)
  E36. t = Dt*Mc(Bt,Ct,Et,ateq)*cos(alpha)                    # pneumatic trail, POSITIVE at small alpha, sign-reverses past ~6.9 deg
  E37. Mzr = Dr*cos(atan(Br*areq))*cos(alpha)
  E38. sarm = R0*(SSZ1 + SSZ2*(Fy/Fz0) + (SSZ3 + SSZ4*dfz)*gamma)*LS
  E39. Mz = -t*(Fy - SVyk) + Mzr + sarm*Fx
  --- TRANSIENT (relaxation length), one call per wheel per physics step ---
  T1.  Get Kxk, Kya from the CHEAP helper stiffnesses(Fz, gamma) = (E6, E11) only. Do NOT run a second full evaluate() just to get them.
  T2.  sigma_kappa = max(Kxk/CFX, SIG_K_MIN=0.05) ;  sigma_alpha = max(|Kya|/CFY, SIG_A_MIN=0.10)      # floors are MANDATORY: at Fz=100 N the unfloored values are 0.0113 m and 0.0405 m, at Fz=25 N they are 0.0028 m
  T3.  BACKWARD EULER on the state, unconditionally stable for any dt:  tan_kappa <- (tan_kappa + dt*(-Vsx)/sigma_kappa) / (1 + dt*|Vx|/sigma_kappa)
  T4.  tan_alpha <- (tan_alpha + dt*(Vsy)/sigma_alpha) / (1 + dt*|Vx|/sigma_alpha)
  T5.  Rationale: the exact ODEs are  sigma_k*d(tan_kappa)/dt + |Vx|*tan_kappa = -Vsx  and  sigma_a*d(tan_alpha)/dt + |Vx|*tan_alpha = Vsy. At high |Vx| the update converges to the steady-state slips -Vsx/|Vx| and Vsy/|Vx| = tan(alpha_SAE) EXACTLY (this is why the state is tan(alpha), not alpha). At Vx = 0 the denominator becomes 1 and the update degenerates to a pure integrator: the tyre behaves as a lateral spring of stiffness Kya/sigma_alpha == CFY. It cannot blow up because the denominator is never < 1.
  T6.  clamp tan_kappa to [KPUMIN, KPUMAX] = [-1.5, 1.5] ;  clamp tan_alpha to [-10, 10]  (atan(10) = 1.471 rad, safely inside ALPMAX = 1.5 rad). The clamps stop unbounded wind-up when the car is parked and being pushed.
  T7.  kappa = tan_kappa ;  alpha = atan(tan_alpha) ;  then run E1..E39 ONCE.
  --- LOW-SPEED DAMPING AND FRICTION CAP ---
  L1.  if |Vx| < VXLOW = 1.0:  f = 0.5*(1 + cos(pi*|Vx|/VXLOW))    # raised cosine, C1-continuous, = 1 at Vx=0, = 0 and zero-slope at Vx=VXLOW
  L2.  Lfz = min(1.0, Fz/2477.0)                                    # so an airborne wheel cannot be damped
  L3.  Fx -= KDX*f*Lfz*Vsx    with KDX = 2*ZLOW*sqrt((m_corner + Iw/Re^2)*CFX) = 2*0.7*sqrt(260.6*381913.4) = 13967 N.s/m
  L4.  Fy -= KDY*f*Lfz*Vsy    with KDY = 2*ZLOW*sqrt(m_corner*CFY)         = 2*0.7*sqrt(252.5*157632.5) =  8832 N.s/m
  L5.  Explicit-integration stability of L3/L4: dt < 2*m_corner/KDY = 2*252.5/8832 = 0.0572 s. At 1000 Hz that is a 57x margin; at 100 Hz still 5.7x.
  L6.  FRICTION-ELLIPSE CAP (this is what stops the damper from inventing grip):  e = sqrt((Fx/(mux*Fz))^2 + (Fy/(muy*Fz))^2) ;  if e > ECAP = 1.05:  s = ECAP/e ;  Fx *= s ; Fy *= s ; Mz *= s
  L7.  ECAP must be 1.05, not 1.00: the measured maximum of e over the pure MF combined-slip grid (kappa in [-0.6,0.6], alpha in [-20,20] deg, Fz in {1200,2477,3500,5000}) is 1.0354, so a cap at 1.00 would clip 3.5% of legitimate MF force.
  L8.  REVERSE:  if Vx < 0:  Mz = -Mz.  The pneumatic trail sits behind the contact centre relative to the direction of travel, so self-aligning torque becomes DE-stabilising in reverse. This one line is what makes reversing feel correct.
  --- OPTIONAL ROLLING RESISTANCE MOMENT (about the wheel y-axis) ---
  R1.  My = -Fz*R0*(QSY1 + QSY3*|Vx|/LONGVL + QSY4*(Vx/LONGVL)^4)*(Fz/Fz0)^QSY7*sgn(omega)    # LONGVL = 16.7 m/s. Gives an effective Crr of 0.00516 at 10 m/s, 0.00690 at 30 m/s, 0.01087 at 47.2 m/s, all at Fz=2477 N.
  R2.  Use EITHER R1 OR corsa_c.Crr = 0.012, never both. R1 at Vmax gives 0.01087 vs the 0.012 that eta_drive = 0.86 was calibrated against, which moves Vmax from 47.2 to ~47.5 m/s (170 -> 171 km/h) — inside the CdA band 0.64-0.70, so R1 is acceptable and gives better coast-down feel at low speed.

API:
  def load_tir(path: str) -> dict[str, float]
      Parse a .tir file into an upper-cased name -> float dict. Strip everything after '$' (comment marker), match r'\s*([A-Za-z_0-9]+)\s*=\s*(-?[\d.eE+-]+)\s*$'. Ignore quoted string fields. Handles the tab-aligned MagicFormula61_Paramerters.tir layout as well. Called exactly once per file, at module import. Copy the parser from tyre_data/mf_eval.py but NOT its `files` list — that list points at a non-existent tir/ subdirectory; the .tir files sit directly in tyre_data/.
  class TyreModel:
    def __init__(self, tir_path: str, *, symmetrise: bool = True, R0: float = 0.2915,
                 width: float = 0.175, LFZO: float = 1.0, LMUX: float = 1.0,
                 LMUY: float = 1.0, LKY: float = 1.0, LKX: float = 1.0,
                 CFX: float = 381913.4, CFY: float = 157632.5) -> None
      Immutable, thread-safe, load-once. Parses the file, applies the symmetrisation zeroing, then UNPACKS every coefficient it needs into individual instance attributes declared in __slots__ (never a dict — dict lookups in the hot loop cost ~30% of the call). Precomputes Fz0 = LFZO*FNOMIN, inv_Fz0 = 1/Fz0, R0_over_Fz0 = R0/Fz0, TWO_OVER_PI = 0.6366197723675814, and the fused scalers. Raises ValueError if FITTYP is present and != 62 (the MF6.2 Kya and camber forms below are wrong for FITTYP 61/pac2002 files).
  def evaluate(self, Fz: float, kappa: float, alpha: float, gamma: float = 0.0, mu_scale: float = 1.0) -> tuple[float, float, float]
      THE hot function. Full MF6.2 combined slip, equations E1..E39 in order. Returns (Fx, Fy, Mz) in N, N, N.m in the wheel-carrier frame. Pure, allocation-light, no branches except the four min()/sgn() clamps. Measured 1.78 us/call on this machine at gamma=0, mu_scale=1.0; ~2.0 us with both active. Fx > 0 accelerates, Fy < 0 for alpha > 0, Mz > 0 for alpha > 0 (restoring).
  def stiffnesses(self, Fz: float, gamma: float = 0.0) -> tuple[float, float]
      Returns (Kxk, Kya) — equations E6 and E11 only, ~0.3 us. These depend on Fz and gamma but NOT on kappa or alpha, which is exactly why the relaxation-length update can be done before the single evaluate() call instead of paying for two full evaluations per step. Kya is negative.
  def relax_lengths(self, Fz: float, gamma: float = 0.0) -> tuple[float, float]
      Returns (sigma_kappa, sigma_alpha) in m: max(Kxk/CFX, 0.05), max(abs(Kya)/CFY, 0.10). Convenience wrapper over stiffnesses(); step_contact inlines it.
  def mu_y(self, Fz: float, mu_scale: float = 1.0) -> float
      The MF D-term friction coefficient, (PDY1 + PDY2*dfz)*LMUY*mu_scale. This is EXACTLY qss.py's mu(Fz) = 0.903 - 16.1e-6*(Fz - 2477) at mu_scale = 1.0, to within 4.5e-5 absolute over Fz in [500, 6000] N. Provided so the QSS solver and the real-time sim can be shown to share one tyre.
  def peak_fy(self, Fz: float, mu_scale: float = 1.0) -> float
      Peak lateral force = mu_y(Fz, mu_scale)*Fz, returned analytically (no search). After symmetrisation this equals the numerically-swept peak of |Fy0(alpha)| to 5 significant figures at every load, because the MF sine argument Cy*atan(x) reaches pi/2 for Cy = 1.3332 > 1 and SVy = 0. This is the function to monkey-patch into qss.fy_max for the acceptance test.
  def mu_x(self, Fz: float, mu_scale: float = 1.0) -> float
      Longitudinal D-term, (PDX1 + PDX2*dfz)*LMUX*mu_scale. Needed by the caller for the friction-ellipse cap; 1.0737 at 2477 N, i.e. 1.19x mu_y — braking grip legitimately exceeds cornering grip on this tyre.
  def rolling_resistance_moment(self, Fz: float, Vx: float, omega: float) -> float
      Equation R1. Returns My in N.m, negative for forward rotation (resisting). OPTIONAL — see the pitfall about double-counting with corsa_c.Crr.
  class ContactPatch:
    __slots__ = ('tan_kappa', 'tan_alpha')
    def __init__(self) -> None
    def reset(self) -> None
      Per-wheel transient state. Four instances live in the vehicle module. Two floats each — the entire memory footprint of tyre transience. reset() zeroes both (call on respawn/teleport).
  def step_contact(tyre: TyreModel, cp: ContactPatch, Fz: float, Vx: float, Vsx: float,
                 Vsy: float, dt: float, gamma: float = 0.0, mu_scale: float = 1.0,
                 m_corner: float = 252.5) -> tuple[float, float, float]

Vsx = Vx - omega*Re is the longitudinal slip velocity, Vsy is the lateral velocity of the contact point, both in the WHEEL-CARRIER frame (the vehicle module must have already rotated by the steer angle). Handles Fz <= FZ_EPS by returning zeros and decaying the states.

      Module-level singleton, built at import from the absolute path to tyre_data/TNO_car205_60R15.tir with all the defaults above. Parsing costs ~2 ms; it must happen exactly once. Never construct a TyreModel inside the physics loop.

PITFALLS:
  - DO NOT rescale FNOMIN to 2500 N. Load sensitivity in MF is s = PDY2/(LFZO*FNOMIN). At LFZO=1 that is -0.06445/4000 = -16.11e-6/N, exactly qss.py's -16.1e-6. At LFZO = 0.625 it becomes -0.06445/2500 = -25.78e-6/N — 60% steeper — which changes crossover.py's marginal_mu from 0.888 to 0.839, changes the lateral-vs-downforce advantage from 1.126x to 1.192x, and invalidates the entire flank-wing conclusion. FNOMIN is the TYRE's rated load, not the car's operating load, and 4000 N happens to be right for a 175/65R14 82T (load index 82 = 4660 N max) as well as for the 205/60R15 it was measured on. Rescale geometry (R0, WIDTH, ASPECT_RATIO, RIM_RADIUS) and nothing else.
  - SYMMETRISE OR THE CAR PULLS. With the raw file, peak|Fy|/Fz at Fz=2477 is 0.9233 for positive alpha and 0.8830 for negative (from SVy = -50.3 N of ply-steer thrust), 2.3% above qss's 0.903 and asymmetric; and Mz(0,0) = +1.75 N.m per wheel from QDZ6, giving a permanent phantom self-centring torque at dead-ahead. Zero all thirteen camber-EVEN shifts: PHY1 PHY2 PVY1 PVY2 PHX1 PHX2 PVX1 PVX2 QHZ1 QHZ2 QDZ6 QDZ7 QSX1. Do NOT zero PVY3 PVY4 QHZ3 QHZ4 QDZ8 QDZ9 QDZ10 QDZ11 — those are camber-ODD and are real physics that flip with the wheel. Do NOT zero RHX1 RHY1 RHY2 — the combined-slip kernels self-normalise at their own shift (Gxa(0) = Gyk(0) = 1 exactly), so they cause no asymmetry. QDZ6 is the one everyone misses.
  - mf_eval.py's file list points at 'tir/TNO_car205_60R15.tir'. There is no tir/ subdirectory — the .tir files are directly in tyre_data/. Copy mf_eval's load() function, not its main block.
  - mf_eval.py's camber is MF5.2, not MF6.2. It writes SHy = (PHY1 + PHY2*dfz)*LHY + PHY3*gamma. A FITTYP=62 file has no PHY3 (mf_eval's g() silently returns 0.0), so camber thrust comes out as ZERO. The MF6.2 form is SHy = (PHY1 + PHY2*dfz)*LHY + (Kyg0*gamma - SVyg)/Kya with Kyg0 = Fz*(PKY6 + PKY7*dfz)*LKYC. Test: dFy/dgamma at Fz=3022, alpha=0 must be -44.5 N/deg, not 0.
  - mf_eval.py's non-mf6 Kya branch multiplies by LFZO a SECOND time and uses sin(2*atan(...)) instead of sin(PKY4*atan(...)). This file is FITTYP=62, so take the mf6 branch. Guard it: raise if FITTYP != 62 rather than silently evaluating a 6.2 file with 5.2 equations.
  - THE RELAXATION STATE MUST BE tan(alpha), NOT alpha. The ODE sigma*d(x)/dt + |Vx|*x = Vsy has steady state x = Vsy/|Vx|, which IS tan(alpha_SAE), not alpha. Storing alpha directly makes the transient converge to the wrong limit at large slip (7% low at 20 deg, 27% low at 40 deg). Store tan_alpha, feed atan(tan_alpha) to the MF.
  - USE BACKWARD EULER, NOT EXPLICIT EULER, ON THE RELAXATION ODE. Explicit Euler is stable only for dt < sigma/|Vx|, which at Fz=1000 N (sigma_alpha = 0.111 m) and 30 m/s means dt < 3.7 ms — a frame hitch instantly explodes the tyre. The backward form x <- (x + dt*Vsy/sigma)/(1 + dt*|Vx|/sigma) has a denominator that is never less than 1, is unconditionally stable, converges to the correct steady state at high speed, and degenerates to a clean integrator at Vx = 0 (which is exactly the tyre-as-a-spring behaviour you want when parked). Verified identical answers from dt = 1 ms to dt = 10 ms.
  - THE sigma FLOORS ARE NOT OPTIONAL. sigma_alpha = |Kya|/CFY collapses to 0.0113 m at Fz = 100 N and 0.0028 m at Fz = 25 N, and it appears in the denominator of the ODE gain. On a wheel that unloads over a kerb the update gain dt*Vsy/sigma goes to hundreds. Floor at SIG_A_MIN = 0.10 m and SIG_K_MIN = 0.05 m.
  - THE LOW-SPEED DAMPER WILL MANUFACTURE GRIP UNLESS YOU CAP IT. KDY = 8832 N.s/m means that at Vy = 0.34 m/s the damper alone produces 12000 N — more than the tyres' 8917 N total capacity. Without the cap a car pushed at 12000 N from standstill wrongly settles at 0.11 m/s instead of accelerating at 3.05 m/s^2. Apply the elliptical cap e = hypot(Fx/(mu_x*Fz), Fy/(mu_y*Fz)) with ECAP = 1.05 AFTER adding the damper. ECAP must be 1.05, not 1.00: the measured maximum of e over the pure MF combined grid is 1.0354, so a 1.00 cap silently clips 3.5% of real force in the near-pure-longitudinal region.
  - MZ MUST FLIP SIGN IN REVERSE. Pneumatic trail is behind the contact centre relative to the direction of travel, so self-aligning torque is de-stabilising when reversing. One line — `if Vx < 0: Mz = -Mz` — is the difference between a car that reverses like a car and one that reverses like a forward-driving car with the video flipped. Everything else in the model is already correct in reverse because kappa = -Vsx/|Vx| and alpha = atan2(Vcy, |Vcx|) use absolute values.
  - mu_scale MUST DIVIDE Bt AND Br, NOT JUST MULTIPLY Dy. A naive wet implementation that only scales the peak leaves the pneumatic-trail shape factor Bt = (QBZ1 + QBZ2*dfz)*LKY/LMUY unscaled, so the wet tyre's Mz peaks at the dry slip angle instead of the wet one. Scale LMUX and LMUY into ONE fused pair of locals at the top of evaluate() and use them in every one of Dx, Dy, SVyg, DVyk, Bt, Br, Dr.
  - GET THE WHEEL-ODE SIGN RIGHT. It is Iw*domega/dt = T_drive - T_brake*sgn(omega) - Fx*Re. The reaction of the road force on the wheel is MINUS Fx*Re. Writing +Fx*Re makes the wheels spin up without bound (max |Fx| reaching 2.6 MN within six simulated seconds — I hit exactly this while validating). This lives in the vehicle module, but tyre.py's docstring must state the sign convention it returns.
  - DO NOT CALL evaluate() TWICE PER STEP. The relaxation lengths need Kxk and Kya, which are functions of Fz and gamma only — not of kappa or alpha. Get them from stiffnesses() (~0.3 us) before the state update, then call evaluate() once. Calling evaluate() to fetch the stiffnesses doubles the tyre cost for nothing.
  - THE TYRE ALONE CANNOT HOLD STATIC EQUILIBRIUM. Braking to a stop from 5 m/s leaves 0.02-0.05 m/s of residual creep, because the relaxation model has no stiction branch. This is a real limitation, not a bug to hide: the vehicle module must add a clamp of the form `if |V| < 0.05 and |demanded longitudinal force| < mu*Fz_total: V = 0`. Say so at the handoff rather than letting the implementer discover the car slides down a slope.
  - DO NOT USE BOTH rolling_resistance_moment() AND corsa_c.Crr = 0.012 — that double-counts. corsa_c's eta_drive = 0.86 was back-solved from the Vmax power balance WITH Crr = 0.012 (aero 882.2 N + rolling 118.9 N = 1001 N at 47.2 m/s = 47.3 kW = exactly P_wheel). The MF My gives an effective Crr of 0.00516 at 10 m/s, 0.00690 at 30 m/s and 0.01087 at 47.2 m/s, which would push Vmax to ~47.5 m/s (171 km/h vs the published 170). Either is defensible; pick one and state it.
  - qss.py AND crossover.py DEFAULT TO alpha_peak_deg = 7.0 AND THAT IS TOO LOW. The MF front-axle peak at the R=100 grip-limit load distribution (outer 5463 N, inner 581 N) is 10.35 deg. Because scrub drag is m*a_y*sin(alpha_peak), this raises the drag term by sin(10.35)/sin(7.0) = 1.47x and moves every POWER-limited answer: qss.corner_speed(130) drops 31.880 -> 29.033 m/s, corner_speed(175) drops 34.012 -> 31.217, and crossover.sustainable_V(0.87) drops 30.67 -> 24.76 m/s (R_cap 100.7 m -> 65.7 m). This shrinks the radius band over which the flank wing can act. It is a finding about the study, not about the sim — escalate it rather than silently using 7.0 in the driving sim's telemetry.
  - GAMMA'S SIGN IS COUPLED TO ALPHA'S. In this file PKY1 = -15.314 and PKY6 = -0.9004, so BOTH positive alpha and positive gamma produce negative Fy. Wire the vehicle module's camber so that dFy/dgamma at Fz=3022, alpha=0 comes out at -44.5 N/deg; if you get +44.5 you have the roll-camber sign inverted and the twist beam will help instead of hurt. Reassuringly, it barely matters: at the R=100 limit the camber sensitivity has decayed to 1.6 N/deg, so 4.6 deg of adverse rear camber costs 0.10% of rear axle capacity — which is the numerical justification for qss.py having disabled its c_cam term.
  - CLAMP tan_kappa TO [-1.5, 1.5] AND tan_alpha TO [-10, 10]. These are the file's own KPUMIN/KPUMAX and (via atan(10) = 1.471 rad) its ALPMIN/ALPMAX. Without them, a car held stationary against a wall integrates the deflection state without bound and then takes seconds to unwind when released.
  - PARSE ONCE. Build CORSA_TYRE as a module-level singleton at import. Unpack every coefficient into __slots__ attributes or function-local names — a dict lookup per coefficient inside evaluate() costs roughly 30% of the 1.78 us budget. There is no need for lookup tables, numpy vectorisation, or a C extension: four tyres at 1000 Hz is 0.71% of one core as plain Python.
